### 🧾 GenAI Receipt Analytics

AI-powered receipt management platform that automates expense tracking using computer vision and generative AI.

**Key Features**
- 📄 Extracts receipt details using OCR and Gemini Vision API.
- 📊 Categorizes expenses and generates spending insights.
- 📈 Interactive dashboard with analytics and visualizations.
- 🔒 Secure authentication and cloud-based data storage.

**Tech Stack**
`Next.js` • `Node.js` • `Express.js` • `Gemini Vision API` • `Tesseract OCR` • `PostgreSQL`

### 😴 Smart Sleep Disorder Detection

IoT-based wearable system that monitors physiological signals and predicts sleep disorders in real time.

**Key Features**
- ❤️ Tracks heart rate, body temperature, and body movements using ESP32.
- 🧠 Machine Learning model predicts multiple sleep disorder classes.
- 📡 Real-time sensor data visualization through a web dashboard.
- 🔋 Portable wearable powered by rechargeable Li-Po battery.

**Tech Stack**
`ESP32` • `MAX30102` • `MPU6050` • `Flask` • `Random Forest` • `HTML` • `CSS` • `JavaScript`

---

### 🧠 Speech-to-Hand Prediction

Machine Learning research project that predicts anthropometric hand measurements from speech features.

**Key Features**
- 🎤 Extracted acoustic features using OpenSMILE.
- ✋ Generated hand measurements from MediaPipe hand landmarks.
- 🤖 Compared Random Forest, XGBoost, and Feed Forward Neural Network models.
- 📄 Research paper submitted based on the project.

**Tech Stack**
`Python` • `OpenSMILE` • `MediaPipe` • `Random Forest` • `XGBoost` • `TensorFlow`
